# Trabajo Práctico N° 2 - EventoUniversitario

* **Materia:** Paradigmas de Programación
* **Legajo:** 53343

## Descripción del Proyecto
Evolución del sistema de gestión `EventoUniversitario` desarrollado en Java orientado a objetos, cubriendo hasta el Ejercicio 4 del TP2 (Excepciones, Persistencia, Interfaces, Generics e Hilos).

## Estructura e Integración de Ejercicios
* **Ejercicio 1:** Modularización en paquetes, excepción `CupoExcedidoException` y persistencia por serialización.
* **Ejercicio 2:** Interfaz `Certificable`, nuevo tipo `Curso` y uso de `instanceof` con Pattern Matching.
* **Ejercicio 3:** Métodos genéricos acotados (`filtrarActividadesPorTipo`) y wildcards (`calcularCostoMateriales`).
* **Ejercicio 4:** Clase anidada `Inscripcion.TicketDeAcceso` y ejecución concurrente con `EnvioTicketsThread`.
